# 验证样例

> 目标：评审按步骤就能体验主要功能，并核对 seekdb 在「检索」与「记忆」两处确实生效。
> 所有样例都不依赖作者本地已有数据：角色池由后端启动时自动 seed，记忆按 `sys.user_id` 隔离。

## 0. 准备

1. seekdb 已启动（`127.0.0.1:2881`）；
2. 后端已启动（`cd dify && npm install && npm start`），`/health` 返回 `personas: 24`；
3. Dify 已导入 DSL、绑定模型、把三个 HTTP 节点 URL 指到后端；
4. 在 Dify 里新建一个会话（新的 `sys.user_id` 即新的记忆空间）。

## 1. 撮合：输入简历 → seekdb 混合检索 → 月老报告

**输入**

~~~text
帮我撮合一下：程序员，28 岁，喜欢猫和手冲咖啡，周末想去看展
~~~

**预期**

- 返回 3 位候选，至少 1 位命中「代码 / 咖啡 / 猫 / 看展」相关标签；
- 每位候选都引用其口头禅与至少一条雷点；
- Dify 的 HTTP 节点返回 `mode: "hybrid"`（说明走的是 seekdb 的向量 + 全文混合检索）；
- 报告写回 seekdb，`/api/history` 能查到本次记录。

**实际运行**（`evidence/demo-1-match.md`，本地等价执行器 + 真实 seekdb 后端）：

~~~text
### 1. 程序员诗人·Linus · 缘分指数 79
- 匹配点：代码、科幻；口头禅「你的笑点，可以写成一个正则。」
- 雷点预警：用英文名；聊技术会忘记时间
### 2. 反内卷先锋·阿卷 · 缘分指数 63
- 匹配点：自由职业、反内卷；口头禅「上班是不可能上班的。」
### 3. 盆栽哲学家·阿植 · 缘分指数 53
- 匹配点：植物、手冲咖啡；口头禅「你看这盆绿萝，像不像你前任？」
~~~

> 本地执行器未接 LLM，报告中的文案为模板占位；接上模型后同一 prompt 会输出更完整的月老语气。

## 2. 换一批：记忆生效 + 排除已见

**输入**（同一个用户，紧接着上一步）

~~~text
再换一批，有没有更疯一点的
~~~

**预期**

- 开场引用上一次的候选人（来自 seekdb 的 `matches`）；
- 本轮候选与上一轮不重复（后端按历史排除已见角色）。

**实际运行**（`evidence/demo-2-next.md`）：

~~~text
## 月老开场
上次你见过「盆栽哲学家·阿植、程序员诗人·Linus、反内卷先锋·阿卷」，月老可都记着呢。
## 今日撮合
### 1. 剧本杀 DM·阿寺 · 缘分指数 78
### 2. 凌晨三点写诗的运营·小满 · 缘分指数 70
### 3. 消费主义批判者·K · 缘分指数 53
~~~

## 3. 查档案：跨轮次（含新会话）记忆

**输入**

~~~text
查一下我的相亲档案
~~~

**预期**

- Dify 的 if-else 命中「档案」分支，走 `/api/history`；
- 输出历史候选人列表与时间，数据来自 seekdb；
- 换一个新会话但使用同一 `sys.user_id`，仍能查到（若平台每次会话 user_id 不同，可用 Dify 的会话变量或固定用户测试）。

**实际运行**（`evidence/demo-3-history.md`）：

~~~text
## 相亲战报
### 盆栽哲学家·阿植、程序员诗人·Linus、反内卷先锋·阿卷 · 2026-11-02
### 剧本杀 DM·阿寺、凌晨三点写诗的运营·小满、消费主义批判者·K · 2026-11-02
## 下一步建议
同一批角色不要反复相，换点新爱好，缘分池会更大。
~~~

## 4. LLM 接线验证（可选，不需要真实模型）

~~~bash
node tools/mock_llm.mjs &          # 本地 mock OpenAI 兼容服务
node tools/run_workflow.mjs --user demo --profile "程序员，喜欢猫" --message "帮我撮合" \
  --llm-base http://127.0.0.1:8080 --llm-model mock-model --save evidence/demo-4-llm-mode.md
~~~

预期：LLM 节点改为调用 `/v1/chat/completions`，回复内容来自模型（mock），
证据里会记录 `mode: llm:mock-model`。这一步证明「Dify LLM 节点 → 模型服务」的链路可用；
真实文案请在 Dify 中绑定自己的模型体验。

## 5. 恢复初始状态

| 目的 | 操作 |
| --- | --- |
| 换一个新的记忆空间 | 在 Dify 里新建会话（新的 `sys.user_id`） |
| 重置角色池 | `curl -X POST http://127.0.0.1:7870/api/seed` |
| 清空全部记忆 | 删除 `matches` collection 或重建 `dify_matchmaker` 数据库后重启后端 |
