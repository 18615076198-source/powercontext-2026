# 验证样例

样例目录：`samples/task-001-report-region-filter/`

| 文件 | 作用 |
| --- | --- |
| `task.json` | 任务定义：要改什么、必须保持什么、允许改哪些路径 |
| `spec-update/02-report.md` | 规格演进后的完整版本（新增 BR-REPORT-05..08） |
| `acceptance/test_acceptance_report_region.py` | 8 条功能验收用例（改动前全部失败） |
| `minimax-output.txt` | 真实 MiniMax 调用的原始输出，供 CI 复现 |

## 1. 要改什么

**需求（`task.json.request` 原文）**

> 月度结算报表需要支持按销售区域（region）过滤：运营同学只导出某个区域的订单，并且区域维度也要在报表里汇总。
> ① 新增 region 参数，不传时行为与现在完全一致；② region 与已有 currency 过滤可以叠加；
> ③ 报表结果里增加按区域的金额汇总，只统计过滤后的订单；④ 区域名输入要容忍前后空格和大小写差异；
> ⑤ 传入不存在的区域时返回空报表而不是报错。

**规格依据（`spec-update/02-report.md`）**

| 条目 | 要求 |
| --- | --- |
| BR-REPORT-05 | `region: str \| None = None`；`strip()` + `casefold()` 比较；空白入参抛 `ValueError`；未知区域返回空报表 |
| BR-REPORT-06 | `currency` 与 `region` 取交集，顺序不影响结果 |
| BR-REPORT-07 | `MonthlyReport.totals_by_region`：只统计过滤后订单，键为 `region.strip()` 原文，`to_dict()` 需输出且按键排序 |
| BR-REPORT-08 | 不传 `region` 时，`order_count`/`totals_by_currency`/`rows` 与改动前完全一致 |

**预期落点（模块检索给出）**

- 代码：`billing.report:build_monthly_report`、`billing.report:MonthlyReport`（`src/billing/report.py`）
- 测试：`tests/test_report.py` 的 8 条回归用例

## 2. 哪些原有行为必须保持

`task.json.must_preserve` 锁定 4 条既有规格：

| 条目 | 不许变的东西 |
| --- | --- |
| BR-REPORT-01 | 只统计 `paid` 且落在目标年月的订单，取消/退款不计入 |
| BR-REPORT-02 | `currency=None` 不过滤；未知币种返回空报表；空白入参抛 `ValueError` |
| BR-REPORT-03 | 按币种分组累加应付金额，禁止混币 |
| BR-REPORT-04 | 明细行按 `order_id` 升序 |

外加两条机制性红线：

1. `tests/` 下 25 条回归用例必须在改动后全部通过；
2. `tests/` 目录文件的哈希在 `verify` 前后必须一致（禁止靠改测试通过）。

## 3. 怎么跑

```bash
cd minimax
export PYTHONPATH=src SDDCTX_STORE=seekdb POWERCONTEXT_URL=http://127.0.0.1:8077
TASK=samples/task-001-report-region-filter/task.json

python -m sddctx import  --task $TASK --reset     # 1. 导入 v1 资料
python -m sddctx plan    --task $TASK             # 2. 应报 3 条规格缺口
python -m sddctx spec-apply --task $TASK          # 3. 规格演进
python -m sddctx import  --task $TASK             # 4. 重新导入
python -m sddctx plan    --task $TASK             # 5. 缺口消失
python -m sddctx apply   --task $TASK             # 6. MiniMax 改代码
python -m sddctx verify  --task $TASK             # 7. 8 + 25 全绿
python -m sddctx save    --task $TASK             # 8. 写入 PowerContext
python -m sddctx resume  --task $TASK             # 9. 新进程回读
```

## 5. 反向验证：上下文不是固定答案

- 把 `specs/02-report.md` 里 `BR-REPORT-05` 的区域名比较规则从 `casefold()` 改成「大小写敏感」，
  再 `import` + `plan`，上下文包里的规格条目内容随之变化，`apply` 生成的代码也必须跟着变
  （`tests/test_context.py::test_pack_follows_updated_spec_after_reimport` 固化了这一行为）。
- 直接改 `specs/` 文件但不重新导入时，`plan`/`apply` 会报「导入后被修改」，拒绝用过期资料改代码。
