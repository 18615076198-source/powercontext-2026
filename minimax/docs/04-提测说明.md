## 4. 已知限制（提测时如实说明）

1. 本机为 Windows，`pylibseekdb` 无 Windows 轮子，**本地演示**使用 `SDDCTX_STORE=sqlite`；
   seekdb 真实路径已在 GitHub Actions（ubuntu）跑通，见 `docs/05-CI验证记录.md`
   （[run #41288537164](https://github.com/18615076198-source/powercontext-2026/actions/runs/41288537164)，10 步全绿）。
2. 为免在 CI 里下载 ONNX 模型，`SDDCTX_SEEKDB_EMBEDDING=off`：此时集合的稠密向量列写入零向量，
   检索完全依赖 seekdb 的全文通道（`where_document={"$contains": ...}`）加本地重排。
   置 `SDDCTX_SEEKDB_EMBEDDING=default` 可启用默认嵌入模型，走向量近邻通道。
3. CI 中的 MiniMax 步骤使用已冻结的真实输出（`samples/.../minimax-output.txt`）以保持可重复；
   在线调用记录见 `runs/task-001-*/trace.jsonl`；冻结输出与本地真实运行产物同源，
   重放后 `report.py` 的归一化哈希与 `apply.json` 中的 `file_hashes` 完全一致。

## 5. 推送与提交

在 `powercontext` 本地仓库（本仓库根目录）执行：

```bash
git remote add submit https://<用户名>:<token>@github.com/18615076198-source/powercontext-2026.git
git push submit 2026-competition-ecosystem
git rev-parse HEAD          # 平台填这个 hash
```

推送完成后到 OceanBase 训练营题目页提交：仓库地址、分支名、commit hash，
以及 `minimax/README.md` 作为运行说明入口。

> 说明：本仓库对 GitHub 的 HTTPS 访问需要 `http.sslBackend=openssl`（schannel 在部分网络下握手失败），
> 已写入仓库本地配置。
>
> 注意：`minimax/.env` 含密钥，已在 `.gitignore` 中排除，推送前可用
> `git ls-files | grep -c '\.env$'` 确认为 0。
