## 3. 这次跑通修掉的三个 seekdb 问题

本地只有 SQLite 路径能跑，seekdb 代码从未真正执行过，CI 首跑就把三处问题暴露了出来：

| 现象 | 原因 | 处理 |
| --- | --- | --- |
| `Unknown database 'sddctx'` | `pyseekdb.Client` 只暴露集合接口，库不存在时不会自动建 | 用 `pyseekdb.AdminClient` 先执行 `CREATE DATABASE IF NOT EXISTS` |
| `Documents provided but no embeddings and no embedding function` | pyseekdb 的集合必须带稠密向量列，不给向量函数就必须显式给向量 | 关 embedding 时写入零向量，检索只走全文通道（`$contains`） |
| 全文检索命中不稳定 | 全文索引异步构建，入库后立即查询可能查不到 | 入库后调用 `collection.refresh_index()` |
